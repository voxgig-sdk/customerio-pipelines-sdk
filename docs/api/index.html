API overview

In general, you'll consume this API through one of our source libraries, our JavaScript client library or any of our server packages.

  • https://cdp.customer.io/v1: The base URL for all Data Pipelines calls in our United States (US) region.
  • https://cdp-eu.customer.io/v1: The base URL for all Data Pipelines calls in our European Union (EU) region.
